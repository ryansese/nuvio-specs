# nuvio-specs

OpenSpec workspace for the Nuvio ecosystem. Source repos are included as submodules under `repos/`:

| Submodule | Upstream |
|---|---|
| `repos/plexio` | https://github.com/ryansese/plexio |
| `repos/NuvioTV` | https://github.com/NuvioMedia/NuvioTV |
| `repos/NuvioMobile` | https://github.com/NuvioMedia/NuvioMobile |
| `repos/NuvioDesktop` | https://github.com/NuvioMedia/NuvioDesktop |
| `repos/YouTubio` | https://github.com/xXCrash2BomberXx/YouTubio |

Clone with `git clone --recurse-submodules`. Specs live in `openspec/`.
